# Agent Center concept

A working, clickable concept of a redesigned Mutual of Enumclaw agent portal. Everything (styles, scripts, logo, and fictional demo data) is inside `index.html`, so there are no folders to upload.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The full demo |
| `architecture-phase-1.html` | Target architecture, phase 1 (linked from the demo footer) |
| `architecture-phase-2.html` | Target architecture, phase 2 (linked from the demo footer) |

## Publish with GitHub Pages

1. Upload these files to the root of the repository's default branch.
2. In **Settings > Pages**, set **Source** to **GitHub Actions** and click **Configure** on **Static HTML**, then commit the suggested workflow.
3. When the run in the **Actions** tab shows a green check, the site URL appears in **Settings > Pages**.

All member, policy, claim, and agency data is fictional. Appetite rules are samples, not MOE underwriting guidance. Reviewers can click **Reset demo** in the top bar to start fresh.
